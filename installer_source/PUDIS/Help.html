OVERVIEW

PUDIS-2.0 (Portable USB Drive Integrity Suite) is a maintenance and monitoring tool designed to help maintain external drives healthy over long periods of time. It performs two major categories of checks:

  • FILE INTEGRITY (Bit-Rot Detection)
  • SURFACE ANALYSIS (Performance & Stability Scans)

The suite works with USB flash drives, portable HDDs/SSDs, and other removable storage devices. It is designed to NOT , modify or change any files unless you explicitly choose to perform a data recovery procedure.

CAPACITY VALIDATION

The suite verifies whether the drive's reported capacity matches its actual usable capacity. Some counterfeit or defective flash drives falsely advertise larger sizes than they can physically store. These devices appear normal until the system writes past their true limit, causing silent data loss.

Utilizing "[6] Full Surface Scan", the suite writes controlled test files across the free space of the drive and reads them back to confirm that all regions are real, stable, and readable. Any mismatch, write failure, or read-back errors are reported back immediately.

TASKS -- FILE INTEGRITY

[1] Scan for Bit Rot
Compares the current cryptographic hashes of all files against the stored baseline. Reports any files that have changed, corrupted, or are missing since the last baseline was established.

[2] Update File Baseline
Scans all current files on the drive and creates a new master hash file listing. This should be run after you intentionally add or remove files.

[3] Re-Generate Recovery Data
Updates PAR2 recovery files. This allows damaged files to be repaired later. Overwrites previous recovery files.

[4] Calibration
Calibration performs several tests to determine the actual performance characteristics of your computer and USB storage device. These settings are then used for improving the time estimates for performing various activities.

TASKS -- SURFACE SCANS

[5] Quick Surface Scan
Reads a small sample to estimate stability and performance. Useful for routine checks.

[6] Full Surface Scan (Sequential Read/Write Validation)
Performs a thorough test by writing test files across the entire free capacity. This verifies that data can be read back without corruption and no hidden capacity limits exist. Temporary test files are deleted after validation.

TASKS -- MISC

[7] Generate Reports
Generates HTML reports capturing current status of the system.

[8] View Logs
Display Logs folder using Windows Explorer.

RECOMMENDED USAGE

New Installations Run Calibrate, Update File Baseline, then run Re-Generate Recovery Data.
Data Retrieval Run Scan for Bit Rot before utilizing stored files.
Maintenance Run Quick Surface Scan monthly and Full Surface Scan every 6 months.
Updates Update baseline and recovery data whenever you change drive contents.

NOTES

Durability Flash drives wear out; regular scans help detect early failure.
Bit-Rot Bit rot affects any device; baselines allow detection of single-bit corruption.
PAR2 PAR2 recovery data is strongly recommended for long-term archival.
Counterfeits Capacity validation protects against counterfeit drives that discard data.
